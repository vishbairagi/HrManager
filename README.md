# HrManager

A comprehensive Human Resource Management application built with Flutter and Dart.

## Overview

HrManager is a mobile application designed to streamline HR operations and management tasks. It provides tools for managing employees, tracking performance, handling HR processes, and improving organizational efficiency.

## Features

- 👥 **Employee Management** - Manage employee information and records
- 📊 **Performance Tracking** - Monitor and track employee performance
- 📅 **Attendance Management** - Track employee attendance and leave
- 💼 **HR Operations** - Streamline HR processes and workflows
- 📱 **Mobile-First** - Responsive design optimized for mobile devices

## Technologies Used

- **Language**: Dart
- **Framework**: Flutter
- **Platform**: iOS, Android

## Getting Started

### Prerequisites

- Flutter SDK (latest version)
- Dart SDK
- IDE (Android Studio, VS Code, or IntelliJ IDEA)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/vishbairagi/HrManager.git
cd HrManager
```

2. Install dependencies:
```bash
flutter pub get
```

3. Run the application:
```bash
flutter run
```
